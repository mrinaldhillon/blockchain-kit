# What the fork adds

This file is a pointer; the facts live in bsc-geth, which supersedes the copy this file held.

- **The inventory** is bsc-geth `docs/fork-features.md`: what the fork adds to bnb-chain/bsc,
  feature by feature, kept current in the change that changes a feature.
- **The contracts** are `docs/specs/` (the bot-facing one is `bot-feed-contract-v1.md`).
- **The code** is the `*_ext.go` files (`git ls-files '*_ext.go'`).

Read the inventory before changing a feature. A feature that changes updates
`docs/fork-features.md` in the same fork commit.
