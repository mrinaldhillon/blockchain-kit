# What the fork adds

This file is a pointer; the facts live in bsc-geth, which supersedes the copy this file held.

- **The inventory** is bsc-geth's feature inventory, which its docs index
  (`docs/fork/README.md`) lists: what the fork adds to bnb-chain/bsc, feature by feature, kept
  current in the change that changes a feature.
- **The contracts** are the fork's shipped specs, in the same index (the bot-facing one is
  `bot-feed-contract-v1.md`).
- **The code** is the `*_ext.go` files (`git ls-files '*_ext.go'`).

Read the inventory before changing a feature. A feature that changes updates
the inventory in the same fork commit.
